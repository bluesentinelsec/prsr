# Security

If you find a security issue in prsr, report it privately. Do **not** open a public GitHub issue or pull request about it.

Use [GitHub private vulnerability reporting](https://github.com/bluesentinelsec/prsr/security/advisories/new) on this repository, or email **bluesentinel@protonmail.com**.

Include:

- Affected version, tag, or commit
- What you observed
- How to reproduce it
- Impact, if you know it

We will acknowledge the report and fix it before any public disclosure when that is reasonable. Ordinary bugs belong in the issue tracker.
